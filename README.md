# Hong Kong Mahjong (香港麻將)

Браузерная игра в маджонг по правилам **Hong Kong** на PHP: вы против трёх ботов.

## Возможности

- Колода 136 плиток (масти 萬/筒/索, ветры, драконы)
- Ходы: добор, сброс, 吃 чоу, 碰 понг, 槓 конг, 和 победа
- Подсчёт фан (минимум 3) и очков
- Сессия PHP — состояние партии сохраняется между запросами

## Запуск

Нужен PHP 8.1+.

```bash
php -S localhost:8080 -t .
```

Откройте http://localhost:8080

## Управление

1. Клик по плитке — выбор, повторный клик — сброс
2. При сбросе соперника — кнопки Чоу / Понг / Конг / Махджонг / Пас
3. **自摸 Выиграть** — объявить победу после своего добора
4. **Новая игра** — сброс очков и новая раздача

## Структура

```
api.php          — JSON API
index.php        — UI
src/             — игровая логика
  Tile.php, Deck.php, Meld.php, Player.php
  WinChecker.php, Scorer.php, AI.php, Game.php
css/style.css
js/game.js
```

## Правила (кратко)

Победа: 4 комбинации + пара, не меньше **3 фанов**.  
Фаны: 自摸, драконы, ветры, 平胡, 對對胡, 混一色, 清一色 и др.
